# BJJ Training Log Tracker

A CLI tool to log and analyze BJJ training sessions.

## Setup
'''bash
pip install rich
python main.py
'''


# Commands
'''bash
python main.py log       # log a new session
python main.py recent    # view recent sessions
python main.py weekly    # weekly load summary
python main.py detail 1  # detail view of session by ID (1)
'''
